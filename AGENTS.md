# AGENTS.md — civic-link

Guidance for agents and contributors working in this repository.

> `README.md` is the front door and follows the **GeneFoundry README Standard v1** (hard
> ceiling 200 lines, fixed section order, machine-checked by `scripts/check_readme.py`).
> Depth lives in `docs/`. Do not grow the README: relocate.

## What this is

`civic-link` is a read-only MCP server over **CIViC** (Clinical Interpretation of Variants in
Cancer, `https://civicdb.org/api/graphql`): molecular profiles, variants, evidence items and
assertions. It is one backend in the GeneFoundry `-link` fleet, federated behind
`genefoundry-router` under the namespace **`civic`**. Scaffolding (MCP plane, Docker, CI) was
cloned from `pgscatalog-link`. Tracking issue:
https://github.com/berntpopp/genefoundry-router/issues/347.

## Two planes (non-negotiable boundary)

- **Data plane** — `config.py`, `ratelimit.py`, `api/`, `queries.py`, `service.py`,
  `shaping.py`. Calls CIViC over async httpx, validates arguments, returns **plain dicts**,
  raises typed `civic_link.exceptions` errors. Never builds envelopes.
- **MCP plane** — `mcp/`. `run_mcp_tool` (`mcp/envelope.py`) owns `success`/`_meta` and turns
  exceptions into **returned** `isError` envelopes (never raised to the client).

## Invariants

- **Live API only, no data snapshot.** Nothing is stored beyond the in-process TTL cache in
  `api/client.py` and the 24 h in-memory nightly variant index (HGVS / ClinVar lookups).
- **One fixed GraphQL document per tool** (`queries.py`). Never accept caller GraphQL.
  Variables are named after the tool parameter they carry so a `Variable $x` error names `x`.
- **GraphQL errors arrive as HTTP 200 + `errors[]`.** The client maps them to typed errors;
  upstream text is never echoed.
- **Unknown IDs are `not_found`.** CIViC answers `null` for an unknown ID and `totalCount: 0`
  for an unknown name; the data plane maps both to `not_found` naming the argument. Disease and
  therapy filters are checked before use, so they can never empty a result silently.
- **Paging.** CIViC silently caps a page at 100 nodes. `limit` never exceeds it; `total` is
  `totalCount`; offsets map to cursors (`base64(offset)`).
- **Simple vs complex profiles** are listed apart; complex evidence is never folded into a
  single-variant answer.
- **Classification axes stay separate**: `actionability` (AMP tier/level), `oncogenicity`
  (ClinGen/CGC/VICC), `germline_pathogenicity` (ACMG). Never one "significance" verdict.
- **Assemblies.** Every coordinate block and genomic HGVS carries `assembly`; CIViC's primary
  coordinates are GRCh37. Diseases are DOID.
- **Empty is not negative.** Zero evidence says "No CIViC evidence found", never "not
  actionable".
- **Politeness.** Every upstream request passes the process-wide `RateLimiter` (default 0.3 s
  spacing, 20,000/UTC day). Do not bypass it, including in live tests. The User-Agent names the
  product, version and project URL only — never user data.
- **Untrusted text.** Curator prose (evidence statements, assertion summaries/descriptions,
  gene/profile descriptions, source titles) is fenced with `fence_untrusted_text`.
- **6-code error taxonomy**: `invalid_input`, `not_found`, `ambiguous_query`, `rate_limited`,
  `upstream_unavailable`, `internal`.
- Tools publish no `outputSchema` (Tool-Surface Budget Rule 3); every input property has a
  description, required ones carry `examples`, closed vocabularies are `Literal` enums.
- Keep `mcp/capabilities.py::TOOLS` equal to the registered tool set and the README `## Tools`
  table in sync (both tested).

## Fleet deploy contract

`docker/docker-compose.npm.yml` (deployed by the fleet controller `strato_v6_docker_npm`)
declares `user: "10001:10001"` — this image's own uid:gid from `docker/Dockerfile`. `user` must
NOT appear in `docker/docker-compose.yml` / `docker/docker-compose.prod.yml` (the release gate
forbids it). Guard: `tests/unit/test_deploy_overlay_user.py`. Both reusable-workflow pins
(`container-ci.yml`, `container-release.yml`) track the same `genefoundry-router` revision.

Release checklist: bump `pyproject.toml`, `uv lock`, `CHANGELOG.md` heading
`## [x.y.z] - YYYY-MM-DD`, `CITATION.cff` `version:` (generated by the router's
`make citation-write`), tag `vx.y.z`, approve the `release` environment gate via
`gh api repos/berntpopp/civic-link/actions/runs/<id>/pending_deployments` (it can gate more than
once). **Never `gh release create`** — the workflow creates the immutable release.

## Definition of done

`make ci-local` green: format-check, lint-ci, lint-loc (≤500 lines/file), lint-readme,
lint-surface, mypy `--strict`, tests. Unit tests are network-free: `respx` replays recorded
CIViC responses. Live checks are opt-in
(`make test-integration`, a handful of polite calls).

## Make targets

```
make install          # uv sync --group dev
make ci-local         # the definition-of-done gate
make test             # unit tests
make test-integration # live CIViC calls (opt-in, rate-limited)
make dev              # unified HTTP server on 127.0.0.1:8000
make mcp-serve        # stdio MCP server
make docker-up        # Docker stack; make docker-url prints the MCP URL
```

## Conventions

- Python 3.14, `uv`, hatchling; structlog to **stderr only** (stdout is the stdio protocol).
- TDD: failing test first. Files under 500 lines.
- `tests/conformance/` and `scripts/check_readme.py` / `scripts/surface.py` are vendored
  byte-identical from `genefoundry-router`; do not edit them here.
